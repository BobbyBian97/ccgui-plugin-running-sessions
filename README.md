# 运行中会话

在 CC GUI 右侧面板的**「运行中会话」**页签里，跨全部项目实时回显本窗口正在执行的会话轮次：项目、引擎、耗时、**会话标题**与最近活动；卡片带**已读/未读**状态，点击即可跳转到对应会话。

## 功能

- **跨全部工作区**：不管会话属于哪个项目，只要在本窗口执行就会出现，按工作区路径归并
- **卡片信息**：项目名、引擎（Claude / Codex / Gemini / Qwen / Kimi / OpenCode / DeepSeek）、运行时长、会话短 id、标题、最近活动与错误摘要
- **标题行**：与左侧会话列表同源（`custom_title || title`），从宿主会话库只读查询
- **状态**：运行中 / 等待授权（呼吸点）/ 正在收尾 / 完成 / 已取消 / 失败；顶部徽标显示运行中轮次数量
- **已读 / 未读**：新轮次默认未读（卡片蓝点；已结束的未读卡额外显示「未读」标）。点击卡片打开会话，或点卡片内「标为已读」，整卡转已读
  - 未读轮次**无论处于什么状态都保留**（含已完成/失败）
  - **已读且已结束**的轮次 30 秒后消失
  - 最多保留 200 个轮次（内存兜底），超限时按「已读终态 → 未读终态 → 活动轮次」淘汰最老的
- **点击跳转**：调用宿主 `host:session` 打开对应会话；跳转期间其它卡片禁用，避免重复点击
- **手机 / 外部客户端轮次**：从手机（经中转）或其他客户端发起的轮次没有本窗口的 turn hooks，插件通过引擎进程检测补上：出现在面板并标「外部」章，结束后转为「已结束」（未读照常保留）
- **只读**：不发送消息、不修改会话数据，不在磁盘持久化会话内容

## 安装

- 本地目录：CC GUI → 插件 → 从本地目录安装 → 选择本仓库根目录（含 `manifest.json`）
- 手动：把 `main.js`、`manifest.json` 复制到 `%USERPROFILE%\.ccgui-next\plugins\running-sessions\`，在 `plugins.json` 中登记该插件后重载应用

## 权限说明

| 权限 | 用途 |
|---|---|
| `ui:panel-tab` | 注册右侧「运行中会话」页签 |
| `runtime.events.read` | 订阅轮次开始 / 运行事件 / 结束事件，构建会话卡 |
| `host:session` | 点击卡片时跳转到对应会话（只读） |
| `exec:node` / `exec:python` | 只读查询本机会话库以取标题；`node` 另用于枚举 CC GUI 子进程识别外部轮次，不联网 |

## 数据来源与限制

- **标题**：宿主未开放读取标题的插件 API，插件经 `exec` 授权用 `node:sqlite`（失败回退 `python` 标准库 `sqlite3`）只读打开 `~/.ccgui-next/app.db` 的 `sessions` 表查询 `title` / `custom_title`，与左侧会话列表同源。会话库尚未落行的新会话回退读取 `~/.claude*/projects/*/<sessionId>.jsonl` 的首条 user 消息。缓存：标题 60s、缺失 15s、查询失败冷却 60s。
- **本窗口 + 外部客户端**：本窗口发起的轮次来自 turn hooks（事件级状态）；手机 / 其他客户端发起的轮次宿主不派发 hooks，改由进程检测补录——用 `node` 经 PowerShell CIM 枚举 CC GUI 主进程的子进程，按命令行识别引擎 CLI（`claude.cmd` / `node .../claude-code/cli.js` 等）与 `--resume` / `--session-id` 会话标识；工作区从会话库或 Claude 转录的 `cwd` 解析；新会话首轮没有 `--resume` 时，按「进程启动后新生、`cwd` 属于已知工作区的转录」推断会话标识。面板挂载时每 ~10 秒探测一次（未挂载时 60 秒；探测失败指数退避）。
- **外部轮次的状态粒度较粗**：只有「运行中 → 已结束」两态（进程存在与否），看不到等待授权/工具活动，也没有退出码；同一会话已有本窗口的轮次时以本窗口数据为准，不重复显示。
- **平台限制**：进程检测依赖 Windows PowerShell，非 Windows 平台只会显示本窗口轮次（探测失败自动退避，无副作用）。
- **加载前已结束的轮次不显示**：插件加载 / 页面重载（F5）前已结束的轮次不会被回溯补录；加载前仍在执行的外部轮次会在下一次探测时出现。
- **已读状态不持久化**：只存在内存中，页面重载后按新事件重建（新轮次仍默认未读）。
- **不联网**：插件不发起任何网络请求。

## 兼容性

- CC GUI 桌面版（Tauri v2 + WebView2，Windows），`sdkVersion ^0.3`
- 当前版本 0.1.3
